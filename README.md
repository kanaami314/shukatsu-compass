# 就活コンパス

企業・選考状況・志望度・紹介元、説明会の内容と感想、予定と空き時間を管理するWebアプリです。

- 記録はユーザーごとにD1に保存します。
- 日時は日本時間。空き時間は登録された予定を対象に9〜20時から検索します。
- Google Calendar等の外部カレンダーとは未連携です。
- 企業概要はTavilyの基本検索で公式サイト候補を探し、URL contextで読み取りに成功した公式ページのみ要約します。公式URL指定時は検索を省略。同名企業は候補の所在地と参照元で確認します。秘密設定 TAVILY_API_KEY が必要です。1操作につき基本検索1回、追加検索・自動再試行は行いません。URL指定時はTavilyを呼びません。
- タスクは締切日・任意の時刻・優先度・関連先・完了状態を保存し、未完了の締切を週カレンダーにも表示します。
- エージェント面談、個人の予定、複数日の終日予定に対応。終日予定の終了日は含む形で入力し、内部では翌日0時を終了として保存します。
- ノートはGeminiで校正し、原文と比較して採用後に保存できます。送信はクリック時の本文と感想のみ。無料枠のデータ利用について画面に表示します。
- Sitesの秘密環境変数 `GEMINI_API_KEY` が必要です。任意の `GEMINI_MODEL` の既定値は `gemini-3.6-flash`。キーを設定した後は再デプロイが必要です。キーをソース・ブラウザに保存しないでください。
- `.env.gemini` はキー受け渡し用のローカルファイルで、Git対象外です。実行環境へは自動反映されません。
- ローカル動作確認用データは公開先に含まれません。

開発: `npm run dev` / 構築: `npm run build`

検証: `node --experimental-strip-types verify-model.mjs` / 起動中のローカルサーバーで `./verify-api.ps1`

AI校正の検証: `node --experimental-strip-types verify-proofread.mjs`（外部APIを呼ばず、入力制限・応答・失敗時の扱いを確認）。実キーでの接続確認は架空のノートを使用します。

D1スキーマの変更時は `npm run db:generate` でマイグレーションを生成します。
