# 就活コンパスの保存とバックアップ

- 保存済みデータは無期限。下書きは最終更新から、各履歴は作成から、ごみ箱は削除から暦の1か月（日本時間、同日がなければ月末）で本文を削除します。
- 削除通知は出しません。期限切れ本文を再送で復活させないため、ID・所有者・版番号等の最小限の墓標を保持します。
- 既存のごみ箱で削除日時が不明な記録は、初回処理から1か月の猶予を設けます。
- PCバックアップは毎日09:00とWindowsログオン時。停止中に逃した実行は次回ログオン後に実行します。利用者がログオン中に実行するため、サインアウト中は次のログオンまで保留します。
- 保存先: E:\就活コンパスバックアップ。保存済みデータだけをgzip（最大圧縮）した完全JSONとして保存。クラウドの下書き・履歴・ごみ箱は含みません。
- 内容が同じなら世代を追加しません。通常世代は約1.75GiBまで残し、検証用に256MiBを確保します。新規ファイルの書き込み・展開検証中も合計2GiBを超えないよう、必要な空きがなければ既存ファイルを削除せず中止します。常に直前の正常世代を残し、新旧2世代が収まらない場合は処理を中止します。
- 実行プログラム、Windowsアカウントで暗号化した接続情報、status.jsonは E:\ShukatsuCompassBackup に保存。秘密の接続情報はソースやログに保存しません。
- 状況確認: 上記のstatus.jsonのlastSuccess。手動実行: 同フォルダのrun-backup.ps1。タスク名: ShukatsuCompassDailyBackup。
- 復元: アプリの「下書き・変更履歴・ごみ箱」から.json.gzを選択。内容を確認して一括追加すると、既存データを変更せず関連付けを保持して復元します。同じファイルの再試行は重複追加しません。復元前に現在の保存済みデータもダウンロードします。

## クラウドの期限処理
Sitesの定期タスクは毎日実行し、Sites get_siteからサービス認証を取得してPOST /api/maintenanceを呼び出します。OAI-Sites-Authorization: Bearer と X-Compass-Service の双方に同じサービス認証を送ります。値をログやプロンプトに記載しません。追加のアプリ認証が一致しない要求は拒否します。処理対象は設定済みの所有者だけです。通常の保存済みデータは削除しません。アプリの下書き・復元画面でも同じ処理を実行します。
認証情報を更新した場合は、SitesのCOMPASS_SERVICE_TOKENとPC設定も更新する必要があります。
